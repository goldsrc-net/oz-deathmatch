# Credits

This is a fan-made reconstruction of Oz Deathmatch 3.02. It is not affiliated with or endorsed by
AfterShock Productions. Everything below comes from files OZ itself ships: the 3.02 Steam server
package (`oz3-02_for_steam.zip`, `oz/Credits.txt` and `oz/README.txt`), the 3.0 info zip
(`Oz3_info.zip`) and the OZ 1.7 source release (`readme.txt`). Each entry names its source. Where a
file names nobody, the entry says so instead of guessing.

## Terms stated in the 1.7 source readme

Recorded as the 1.7 source's readme.txt states them. It gives "everyone the permission to use this
code as you see fit as long as you agree to these terms":

- "You cannot distribute modifications of this source code as being new versions of Oz Deathmatch.
  For example, if you add some new variables, you may not release using the Oz name, you must make up
  your own name and change it throughout the source code."
- "If you do use part of this source code for your own modifications, and you release it, you must
  give credit to Oz Deathmatch for what you used."

Half-Life is "a trademark of Valve Software and Sierra Online, used with permission" (3.02
Credits.txt).
